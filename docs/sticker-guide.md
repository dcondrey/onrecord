# Respectful Neighbor sticker

The sticker is a voluntary, visible good-neighbor commitment for an outdoor living space. It is not a
lease, private-property permission, legal defense, safety guarantee, or protection from enforcement.
The QR code points to the [Respectful Neighbor / Considerate Camper standard](https://github.com/writerslogic/onrecord/blob/main/docs/respectful-neighbor-tent-placard.md),
which links to the full community guides.

## Print

- [Single sticker SVG](../web/forms/respectful-neighbor-sticker.svg) — 3.5 × 2.5 inches, suitable for
  a professional sticker printer.
- [Six-up sticker sheet](../web/forms/respectful-neighbor-sticker-sheet.html) — open in a browser and
  print on label stock or heavy paper.
- Regenerate after changing the target or design with `npm run sticker`.

Do not add a person’s name, phone number, recovery code, medical information, or exact location to a
sticker. An optional mutual-aid reference belongs on a separate, private agreement—not a public QR label.
