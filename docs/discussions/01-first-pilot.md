# What should the first governed pilot do?

The project should start with one narrow, useful workflow rather than attempting to become a public
HMIS or live shelter inventory. Which document-replacement, transportation, hygiene, or mutual-aid
workflow would reduce the most friction for people using borrowed devices and paper cards?

Please discuss success measures, failure modes, staffing, consent, and what the pilot must explicitly
exclude. Avoid proposing real client data in this thread.
